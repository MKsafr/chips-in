Tentang Chips-in

Chips-in adalah aplikasi chip virtual untuk membantu teman-teman mencatat permainan Poker dan Blackjack di satu meja.

Cerita kami

Chips-in berawal dari kebutuhan sederhana: kami berempat ingin bermain Poker dan Blackjack bersama, tetapi tidak memiliki chip untuk digunakan. Kami sempat mempertimbangkan untuk membeli chip, namun harganya terasa cukup mahal untuk permainan santai bersama teman.

Dari situ muncul ide untuk membuat alat sendiri. Kami membangun Chips-in sebagai meja chip virtual yang dapat dibuka bersama melalui browser. Dengan membuat room dan membagikan kodenya, teman-teman dapat bergabung dari perangkat masing-masing, melihat saldo chip yang sama, serta mengikuti perubahan selama permainan berlangsung.

Tujuan kami adalah membuat sesi bermain bersama lebih praktis tanpa perlu membeli atau membawa set chip fisik. Aplikasi membantu mengelola saldo, giliran, taruhan virtual, dan hasil ronde untuk Poker maupun Blackjack. Kartu tetap dimainkan secara fisik oleh para pemain; Chips-in hanya membantu pencatatan dan pengelolaan permainan.

Chips-in sama sekali tidak mendukung perjudian atau taruhan asli dan tidak akan digunakan atau dikembangkan untuk tujuan tersebut. Website ini hanya untuk permainan sosial dengan chip virtual yang tidak bernilai uang. Pengguna dilarang menggunakan website, room, atau kode undangan sebagai perantara perjudian, termasuk jika uang atau imbalan diatur di luar website. Chip tidak bisa dibeli, dicairkan, atau ditukar dengan hadiah.

Proyek ini dibuat untuk kebutuhan kami sendiri dan dibagikan agar orang lain yang memiliki kebutuhan serupa dapat mencobanya. Kami berharap Chips-in membantu teman-teman memulai permainan dengan lebih mudah dan menikmati waktu bersama.

Kode sumber proyek tersedia di GitHub — online-poker-chips.

Tim

Chips-in dibuat secara pribadi oleh Ado, Anoy, Isan, dan Kholid.

Our story

Chips-in started with a simple need: the four of us wanted to play Poker and Blackjack together but did not have chips to use. We considered buying a set, but the price felt high for casual games with friends.

That led us to build a tool of our own. We made Chips-in as a shared virtual chip table that friends can open in a browser. Players can join from their own devices using a room code, see the same chip balances, and follow updates as the game progresses.

Our goal is to make playing together more convenient without having to buy or bring a physical chip set. The app helps manage balances, turns, virtual bets, and round results for Poker and Blackjack. Players still use physical cards; Chips-in only helps track and manage the game.

Chips-in does not support gambling or real betting in any way and will not be used or developed for those purposes. This website is only for social games using virtual chips with no monetary value. Users are prohibited from using the website, rooms, or invite codes as an intermediary for gambling, including when money or rewards are arranged outside the website. Chips cannot be purchased, cashed out, or redeemed for prizes.

We built this project for our own use and are sharing it so others with a similar need can try it. We hope Chips-in makes it easier for friends to get a game started and enjoy time together.

The project's source code is available on GitHub — online-poker-chips.
